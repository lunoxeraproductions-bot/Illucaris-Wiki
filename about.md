# About / First Pulse

**Lunoxera Productions** is the studio building Illucaris — currently a one-person operation, working toward a long-term goal of a full persistent-world MMO built on this setting.

That's a big destination, so the actual first step is smaller and more focused: **First Pulse**, a survival roguelite prototype. Its job isn't to be the finished game — it's to prove out the core systems (evolution, mutation, survival pressure) at a small scale before ever attempting to build them at MMO scale. First Pulse is currently in active development and isn't public yet.

This wiki exists to share the world itself while that's being built — the lore, races, and setting are ready now, even though the game isn't. New pages get added as time allows; there's no fixed schedule, but there is a plan.

If Illucaris eventually gets there, the long-term goal is a canon solid enough to lock down, with room for other creators to build on it — the way a tabletop system opens itself up for expansion once its core is settled.

Questions, comments, or just want to see what's next — check back here, or wherever this page got linked from.
